# LocalCapes

**LocalCapes** is a client-side mod for Minecraft 1.20.1 (Fabric & Forge) and 1.21.1 (Fabric & NeoForge) that lets you wear bundled capes or your own PNG capes in-game. Capes are only visible on your own client, and the mod is not needed on servers.

## Features

- **50 bundled Java capes**, grouped by Account, Staff, Physical Events, Virtual Events, Personal, Competition, and Volunteer
- **20 Minecraft Dungeons capes** and **7 Minecraft Dungeons II capes**
- **Dropdown filter** next to the title: Minecraft / Minecraft Dungeons / Minecraft Dungeons II
- One scrolling page in Wiki order; the mouse wheel jumps between categories
- **Hover** any cape to see its name and history
- **Night glow**: capes and elytra glow at night or in dark places (toggleable)
- Capes without an elytra design keep the **vanilla elytra texture**
- **Upload custom PNG capes** in-game (saved to `config/localcapes/`), delete them with the × button

## How to open

- Click the **Cape** button in your inventory
- Press **H**
- Run `/localcapes`

## Requirements

| Version | Requirements |
|---|---|
| 1.21.1 Fabric | Fabric Loader ≥ 0.16.14, Fabric API, Architectury API ≥ 13.0.11 |
| 1.21.1 NeoForge | NeoForge ≥ 21.1, Architectury API ≥ 13.0.11 |
| 1.20.1 Fabric | Fabric Loader ≥ 0.16.14, Fabric API, Architectury API ≥ 9.2.14 |
| 1.20.1 Forge | Forge ≥ 47.3.0, Architectury API ≥ 9.2.14 |

## 中文介绍

**LocalCapes** 是一个纯客户端模组，支持 Minecraft 1.20.1（Fabric / Forge）和 1.21.1（Fabric / NeoForge），可在游戏内佩戴内置披风或自己的 PNG 披风。披风仅在你自己的客户端可见，服务器无需安装。

- **内置 50 件 Java 版披风**，按账号相关、员工、线下活动、线上活动、个人、竞赛、志愿者分类
- **20 件地下城披风**和 **7 件地下城 2 披风**
- 标题旁的**下拉筛选**：我的世界 / 我的世界地下城 / 我的世界地下城2
- 按 Wiki 顺序的单页滚动列表，滚轮按分类跳转
- **悬停**查看披风名称和来历
- **夜晚发光**：夜晚或昏暗处披风和鞘翅会发光（可开关）
- 没有鞘翅图案的披风保留**原版鞘翅材质**
- 游戏内**上传自定义 PNG 披风**（保存到 `config/localcapes/`），点 × 删除
- 打开方式：物品栏**披风**按钮、按 **H**、或输入 `/localcapes`
- 前置要求见上方 Requirements 表格
