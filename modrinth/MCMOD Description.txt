【一句话简介】

纯客户端披风模组，适用于 Minecraft 1.20.1（Fabric / Forge）和 1.21.1（Fabric / NeoForge）。内置 50 件 Java 版披风、20 件地下城披风和 7 件地下城 2 披风，也可以上传自己的 PNG 披风，并支持夜晚发光。


【详细介绍】

LocalCapes 是一个纯客户端模组，支持 Minecraft 1.20.1（Fabric / Forge）和 1.21.1（Fabric / NeoForge）。你可以在游戏内佩戴模组内置的披风，也可以上传自己制作的 PNG 披风。

披风只在你自己的客户端显示，其他玩家看不到，也不需要服务器安装。

【功能】

・内置 50 件 Java 版披风，按账号相关、员工、线下活动、线上活动、个人、竞赛、志愿者分类
・内置 20 件《我的世界：地下城》披风和 7 件《我的世界：地下城 2》披风
・点击界面标题旁的下拉箭头，可在「我的世界」「我的世界地下城」「我的世界地下城2」之间切换
・所有披风按 Wiki 顺序排在同一页，并显示分类标题，滚动鼠标滚轮一次跳到下一个分类
・鼠标悬停在披风上，可查看披风名称和来历
・夜晚发光：夜晚或昏暗处，披风和使用披风贴图的鞘翅会发光，可在界面底部开关
・没有鞘翅图案的披风，装备鞘翅时显示原版鞘翅材质
・游戏内直接上传自定义 PNG 披风（保存在 config/localcapes 文件夹），悬停后点右上角的 × 可删除

【打开方式】

・物品栏中的「披风」按钮
・按 H 键
・输入命令 /localcapes

【前置模组】

・1.21.1 Fabric：Fabric Loader ≥ 0.16.14、Fabric API、Architectury API ≥ 13.0.11
・1.21.1 NeoForge：NeoForge ≥ 21.1、Architectury API ≥ 13.0.11
・1.20.1 Fabric：Fabric Loader ≥ 0.16.14、Fabric API、Architectury API ≥ 9.2.14
・1.20.1 Forge：Forge ≥ 47.3.0、Architectury API ≥ 9.2.14
